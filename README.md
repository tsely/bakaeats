# BAKAEATS
Have you ever gotten decision paralysis when looking for something to eat? Especially when you're hungry? I sure have.. and what better way to decide where to get dinner than to start a whole new project?!
## Changelog
Version 1.0 -  Initial barebones website
- Basic single HTML page with JS controlled scenes
- Hardcoded list of cuisines (21 Most Popular)
- Randomly select a cuisine from the list above
- Randomize self selected cuisines
## Roadmap
Here is a list of things I'd like to implement in the future. There is no timeline for when they will be added as this is a learning project for me. If you'd like to implement your own version of it, feel free to put in a pull request. It's always nice to have another perspective.
### Content
- Restaurants (popular chains)
- Food (sushi, hamburger, burritos, etc)
- Recipes instead of eating out
### Features
- Visualize random selection (spinning wheel)
- Implement location based restaurant API
- Filters (dietary or mood)
- Custom user lists (additional store?)
- Statistics page (local/global)
